clipdmenu

A clipboard manager for X11, built in Rust. A daemon caches your CLIPBOARD selection and copied images via XFIXES; the launcher lists that history through dmenu, rofi, or anything else that speaks CM_LAUNCHER.

Small daemon. Simple launcher. Nothing fancy.

#Features

Minimal Footprint

Two small binaries — clipdmenud and clipdmenu — written in Rust

Zero Bloat

No required runtime dependencies except x11rb

Universal Integration

Works with dmenu, rofi, or any CM_LAUNCHER-compatible menu

Large Payload Support

Handles big clipboard payloads via the ICCCM INCR protocol

Image + Text Caching

Captures the CLIPBOARD selection and copied images via XFIXES

X11 Native

Built directly around X11's clipboard mechanisms, no abstraction layer

#Usage

Run the daemon persistently in the background — add it to your WM or session autostart.

clipdmenud &

Bind clipdmenu to a hotkey in your WM, or via sxhkd. Any dmenu (or CM_LAUNCHER) flags are forwarded as-is.

#Configuration

clipdmenu env vars

VariableDescription
CM_LAUNCHERMenu command (default dmenu), e.g. rofi -dmenu
CLIPDMENU_CACHE_DIRCache dir, default $XDG_CACHE_HOME/clipdmenu
XDG_RUNTIME_DIRIPC socket dir for daemon <=> client communication

clipdmenud flags

FlagDescription
max-items=<num>Max entries to store, default 200
watch-primaryCapture mouse-selection / PRIMARY, off by default

#Limitations

  • X11 only — no Wayland
  • One image slot, by design
  • No encryption — history is stored as plain files under ~/.cache. Treat it accordingly if you copy secrets.
